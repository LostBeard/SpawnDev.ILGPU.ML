## Measured / read facts (diffusers file:line in the agent reports; ComfyUI facts from SpawnGen's taps)
- **Gemma 3 12B** (48 layers, 3840 wide): prompt left-padded with 0 to 1024 tokens (116 real; BOS 2). Hidden states of all 49 slots (embedding, layer 0..46
  outputs, final norm output; layer 47's raw output is not a slot) stacked CHANNEL-MAJOR: [T, 188160], index c * 49 + slot.
- **Connector input normalisation**: per slot, over real tokens x channels: 8 (x - mean) / (max - min + 1e-6), padded positions 0 (ComfyUI fits to 3e-8;
  diffusers may run it in bf16: follow ComfyUI's float32).
- **text_proj_in** Linear 188160 -> 3840, no bias, shared by both connectors.
- **Connectors** (video, audio; independent weights): registers [128, 3840] tiled to 1024 (position p gets registers[p % 128]); real tokens moved to the front in
  order; NO attention mask inside; 2 pre-norm blocks (RMSNorm no affine, eps 1e-6): x += attn(RMS(x)) (30 x 128, q/k/v/out with bias, q/k RMSNorm over all
  heads with weights, 1D RoPE theta 1e4 on positions arange(1024)/4096, angle (2 pos - 1) freq, interleaved); x += FFN 3840 -> 15360 -> 3840 GELU-tanh; final
  RMSNorm no affine. Conditioning [1024, 7680] = video | audio.
- **Transformer** (LTX2VideoTransformer3DModel, 48 layers): video 32 x 128 = 4096, audio 32 x 64 = 2048; proj_in Linear 128 -> 4096 / audio 128 -> 2048 (patch 1);
  caption projections PixArt (Linear, GELU-tanh, Linear) 3840 -> 4096 / 2048; six adaLN embedders (time_embed 6, audio_time_embed 6, av video / audio
  scale-shift 4 each, av gates 1 each), sinusoid 256 [cos | sin] of t = sigma * 1000; block: video self-attn (adaLN 0..2), audio self-attn; text cross-attn
  (no modulation, no RoPE); audio <-> video cross attention (both from the pre-a2v norms, audio head size, cross RoPE on time only); FFNs (adaLN 3..5).
  Block norms RMSNorm no affine. Attention q / k RMSNorm over all heads with weights; RoPE on the full inner dim before the head split. RoPE: video axes
  (t, h, w) from patch-midpoint coordinates in pixels / seconds normalised by (20, 2048, 2048), freqs theta^linspace(0,1,dim/(2*3)) pi/2, angle
  (2 frac - 1) freq, interleaved, the dim % 6 remainder PREPENDED as cos 1 / sin 0; audio 1 axis (seconds, / 20). CHECK rope_type / theta / gated_attn /
  cross_attn_mod against the checkpoint config and the taps. Output head: LayerNorm no affine, (1 + scale) + shift from scale_shift_table + embedded_timestep
  (raw), proj_out 4096 -> 128 / 2048 -> 128. Output = velocity; x0 = x - sigma v.
- **Video VAE decoder**: latents denormalised z std + mean (per channel 128); conv_in 128 -> 1024; mid 5 ResNets; 3 up-blocks of (2,2,2) depth-to-space (drop
  the first frame; F -> 2F - 1) + 5 ResNets each, 1024 -> 512 -> 256 -> 128; PixelNorm, SiLU, conv_out 128 -> 48, unpatchify p = 4 (channel c 16 + w_sub 4 +
  h_sub: width / height order TRAP); causal convs (left pad repeating frame 0, CHECK the config); ResNet: PixelNorm (eps 1e-8) SiLU conv PixelNorm SiLU conv;
  output in [-1, 1]. [1,128,2,2,2] -> 9 frames 64 x 64.
- **Audio VAE decoder**: latent denormalised on the packed [L, 128]; conv_in 8 -> 512, mid 2 ResNets, up 512 -> 256 -> 128 (3 ResNets per level, nearest x2 +
  causal conv, drop the first time row), PixelNorm SiLU conv_out 128 -> 2 (mel 64). [1,8,9,16] -> [1,2,33,64].
- **Vocoder** (HiFi-GAN style): [2, T, 64] -> [128, T]; conv_in k7 128 -> 1024; 5 x (LeakyReLU 0.1, ConvTranspose strides 6,5,2,2,2 kernels 16,15,8,4,4), the
  MEAN of 3 ResBlock1 (k 3/7/11, dilations 1/3/5); LeakyReLU 0.01, conv_out k7 32 -> 2, tanh. 240x: 24 kHz.
- **NVFP4** (gemma fp4_mixed): DONE, Kernels.Nvfp4, bit-exact vs ComfyUI (Nvfp4_GemmaLayer_MatchesComfyUi).

## Stages (each gated against SpawnGen's taps, parity first)
1. Weights: read the checkpoint and Gemma file headers; map names (ComfyUI / original layout vs the diffusers names above).
2. Gemma 3 12B encoder (nvfp4 + fp8 + bf16; streamed: 12B) -> the 49 slots -> normalisation -> text_proj_in vs the enc/ taps.
3. Connectors -> conditioning [1024, 7680] vs the taps.
4. Transformer call 0 (adaLN modules, block 0 and 47, output) vs call/ taps; then both calls.
5. Video VAE decode, audio VAE decode, vocoder vs dec/ taps.
6. The whole template graph; then the spatial upscaler pass.
