## Facts from the taps (differ from a naive reading)
- Adapter order: embed (T5 ids, 32128 rows) -> in_proj -> 6 blocks (x, Qwen3 states, rotary pairs for both sides) -> out_proj -> norm. out_proj BEFORE norm.
- No attention masks anywhere in the adapter.
- Adapter rotary: cos/sin [1, M, 64] for the T5 side, [1, N, 64] for the Qwen3 side.
- c_crossattn: the adapter output rows (M = number of T5 ids), then zero rows to 512. Batch row 0 = negative, row 1 = positive.
- x_embedder input [2, 17, 1, 64, 64]: channel 16 (padding mask) = all zeros. Patch 1x2x2 -> 68 -> 2048. Output [2,1,32,32,2048].
- t_embedder: [2,1] -> 2048 (sinusoidal) -> (linear, silu, linear) -> 2048 and 6144 (adaLN-LoRA shared vector); t_embedding_norm (RMS) on the 2048.
- RoPE: pos_embedder gives rotation matrices [1024, 64, 2, 2] (1024 = 32x32 tokens, 64 = head_dim/2); blocks see [1,1024,1,64,2,2]. No absolute
  position embedding (extra_per_block_pos_emb None).
- Blocks: 28 x (self-attn with q/k RMS norm, cross-attn on 1024-wide context with k/v 1024->2048, MLP 2048->8192->2048), adaLN-LoRA
  (adaln_modulation_{self_attn,cross_attn,mlp}.{1,2} [256,2048] pairs) + the shared 6144 vector. Taps for blocks 0, 13, 27 in/out.
- final_layer -> [2,1,32,32,64] before unpatchify (64 = 16 ch x 2 x 2).

## API (decided, told Lore)
- `AnimaLlmAdapter`: (Qwen3 states [N, 1024], T5 ids [M]) -> context [M, 1024]. Runs once per prompt (callers cache it).
- The DiT takes the context UNPADDED and pads to 512 with zero rows itself (also accepts a 512-row tensor). One context per batch row: CFG = [neg, pos].
- The adapter's weights are `net.llm_adapter.*` INSIDE the DiT file (anima-preview3-base / anima-base-v1.0), not in qwen_3_06b_base: load the adapter
  from the same opened file / GpuWeights as the DiT (one open of the 4 GB file; a name filter per module), never a second open (Lore's ask).
- SpawnGen's use: CLIPTextEncode -> Qwen3 states + T5 ids; the Anima model object runs the adapter once per conditioning entry, caches it across steps,
  passes the unpadded context to the DiT.

## DiT semantics from Diffusers transformer_cosmos.py (read 2026-11-28; Diffusers names -> map to the header's net.* once downloaded)
- Patch embed: x [B, 17, T, H, W] -> reshape [B, C, T/1, 1, H/2, 2, W/2, 2] -> permute (0,2,4,6,1,3,5,7) -> flatten last 4 => feature order
  (C, pt, ph, pw), C-major; Linear 68 -> 2048, NO bias.
- RoPE (head_dim 128): dim_h = dim_w = 128 // 6 * 2 = 42, dim_t = 44; theta 10000 * ntk (rope_scale (2,1,1): t_ntk = 2^(44/42), h/w 1);
  freqs_x = 1 / theta^(arange(0, dim_x, 2)/dim_x); per token: cat([emb_t, emb_h, emb_w] * 2) -> 128 (positions: t, row, col; images T=1 -> t=0).
  Applied to q and k (self-attn only) with apply_rotary_emb(use_real, unbind_dim=-2) = ROTATE-HALF pairing (dims i and i+64). ComfyUI hands it as
  rotation matrices [1024, 64, 2, 2]: CHECK the pairing against the taps (interleaved vs halves) before trusting either.
- Time: Timesteps(2048, flip_sin_to_cos=True, downscale_freq_shift=0) on the timestep value (check what value: the tap's t_embedder.0 input is [2,1]
  = 0.9999667 = sigma, so maybe a scale) -> t_proj [2048]; temb = Linear(2048->2048, no bias) -> SiLU -> Linear(2048->6144, no bias);
  embedded_timestep = RMSNorm(eps 1e-6, affine)(t_proj).
- Block (x28): AdaLNZero(x, e, temb): m = Linear(256->6144)(Linear(2048->256)(SiLU(e))) + temb; shift, scale, gate = chunk3(m);
  n = LayerNorm(eps 1e-6, no affine)(x) * (1 + scale) + shift. x += gate1 * SelfAttn(n1, rope); x += gate2 * CrossAttn(n2, context);
  x += gate3 * FF(n3). Attn: q/k/v Linear no bias; per-head RMSNorm on q and k (Diffusers Attention qk_norm rms_norm, affine; eps: check, 1e-5
  default vs 1e-6); RoPE on q,k for self-attn; SDPA no mask; out Linear no bias. Cross: k/v from context 1024 -> 2048. FF: Linear 2048->8192,
  GELU (exact, not tanh: check), Linear 8192->2048, no bias.
- Final: AdaLN (2 chunks): m = Linear(256->4096)(Linear(2048->256)(SiLU(e))) + temb[:4096]; shift, scale; LayerNorm(1e-6, no affine);
  x * (1+scale) + shift; Linear 2048 -> 64 no bias; unpatchify: unflatten channels as (p_h, p_w, p_t, C) and permute (0,7,1,6,2,4,3,5).
- No learnable abs pos emb in Anima (Lore's tap: extra_per_block_pos_emb None), padding-mask channel all zeros.

## Approach (taps first: [[fb-new-conditioning-path-host-check-taps-first]])
1. Host (CPU, float64 where useful) reference of each stage from the header + Diffusers, checked against the taps stage by stage
